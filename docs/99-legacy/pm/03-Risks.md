## 2. بروتوكول إدارة التغيير (Change Control Procedure)
لحماية المشروع من التشعب (Scope Creep)، يخضع أي تعديل يطلبه المشرف أو يفتارحه عضو في الفريق للقواعد التالية:
1. **عدم التعديل الفوري:** لا يُضاف أي كود أو متطلب جديد مباشرة.
2. **فتح بطاقة تغيير:** يُفتح Issue في GitHub بعنوان: `[Change Request] - وصف التعديل`.
3. **تقييم الأثر:** يدرس قائد الفريق (عمرو) أثر التعديل على (الوقت - الجدول الزمني).
4. **الاعتماد:** إذا كان التعديل لا يهدد موعد التسليم، يُعتمد ويُنقل للوحة الكانبان.
