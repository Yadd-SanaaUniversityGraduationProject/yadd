# Legacy Archive — YADD

> **الحالة:** `LEGACY / NON-CANONICAL`

هذا المجلد يجمع الوثائق التاريخية التي لم تعد تمثل الحالة الحالية للمشروع، مع الاحتفاظ بها لأغراض التتبع وعدم فقدان التاريخ.

## المحتويات

- `pm/` — نسخ تاريخية من وثائق إدارة المشروع قبل اعتماد `docs/01-pm/`.
- `analysis/` — نسخ/Placeholders تاريخية من التحليل قبل اعتماد `docs/03-analysis/`.
- `tech/` — مسارات تقنية تاريخية أو Redirects قديمة.
- `governance/` — لقطات وتقارير حوكمة/تقدم تاريخية مؤرخة.

## قاعدة الاستخدام

لا يستخدم أي ملف هنا كمصدر حقيقة للحالة الحالية. عند التعارض، تطبق أولوية المصادر المحددة في `AI_CONTEXT.md` و`docs/00-governance/README.md`.

نقل الملفات إلى هذا المجلد هو **Repository Organization** فقط ولا يغير معنى القرارات أو المتطلبات التاريخية المحفوظة فيها.
