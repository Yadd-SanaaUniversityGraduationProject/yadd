## مبدأ Single Source of Truth

- القرار يوثق مرة واحدة في Decision Register ثم تشير إليه بقية الوثائق بالرمز.
- المتطلب يوثق مرة واحدة في SRS ثم تستخدم النماذج والتصميم معرف المتطلب نفسه.
- قواعد العمل توثق في Business Rules ولا تعاد صياغتها بشكل متناقض في المخططات.
- لا تنسب للمشروع مقابلات أو ملاحظات ميدانية للمستخدمين لم تُنفذ؛ Evidence المستخدمين الحالي هو `SUR-01`، مع Document Analysis وSimilar Systems كمصادر أخرى.
- هيكل 1447 يبقى أعلى مرجع أكاديمي، وأي اختلاف عن تقنيات جمع البيانات المذكورة فيه يسجل صراحة ويحتاج تثبيتًا مع المشرف/القسم (`GOV-Q04`).
- الفصل الأكاديمي مخرج مشتق، وليس وثيقة تشغيلية لإدارة المتطلبات.

## قاعدة تغيير الحالة

`PROPOSED → ANALYZED → APPROVED` لا يحدث تلقائيًا. يجب أن يوجد قرار مراجعة واضح من الفريق، مع التاريخ والمسؤول في سجل القرارات.
