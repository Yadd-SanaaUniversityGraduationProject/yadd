# YADD UX Principles — Working Draft

> **Status:** NOT STARTED / STRUCTURE ONLY

This file will document UX principles derived from project evidence, constraints, and usability findings.

## Planned Areas

- Task-first information hierarchy.
- RTL-first Arabic interaction design.
- Low-bandwidth / low-connectivity resilience.
- Clear authentication boundaries for guests.
- Reduced cognitive load and limited competing CTAs.
- Explicit states for loading, empty, error, pending, rejected, and disabled conditions.
- Clear separation between Chat, Transaction, Invoice, and external payment.
- Privacy-safe public provider presentation.
- Accessibility and readable contrast.

## Evidence Rule

Do not frame demographic assumptions about Yemeni users as facts. Any user-behavior claim must be supported by research/usability evidence or marked as Assumption / Needs Verification.
