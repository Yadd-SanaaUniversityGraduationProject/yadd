# وصف النظام المقترح — Working Model

> **الحالة:** `PROPOSED`

YADD مقترح كمنصة محلية تربط طالبي الخدمات بمقدميها، وتتيح أيضًا اكتشاف منتجات الأسر المنتجة ضمن النطاق الجغرافي المحدد.

## Capabilities مقترحة للتحليل

1. إدارة حساب/ملف مستخدم ودور.
2. تصنيفات ومناطق/أحياء.
3. استعراض مقدمي الخدمات/المنتجات.
4. إنشاء طلب خدمة.
5. استقبال/إرسال عروض على الطلب.
6. التفاوض وتسجيل الاتفاق النهائي — التفاصيل `BUS-Q04`.
7. توثيق معاملة/فاتورة — التفاصيل `BUS-Q05`.
8. تقييم مرتبط بمعاملة — التفاصيل `BUS-Q06`.
9. Portfolio/Product Catalog.
10. إدارة المنصة.
11. التحقق/AI — **غير محسوم ويعتمد على AI-Q01**.

هذه القائمة ليست FR list. التحويل إلى FR يحدث في SRS مع Source/Acceptance notes.
