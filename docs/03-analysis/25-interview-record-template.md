# قالب تسجيل مقابلة ميدانية — YADD

> **الحالة:** `NOT PLANNED / RETAINED FOR TRACEABILITY`

قرر الفريق عدم تنفيذ المقابلات الميدانية ضمن خطة جمع البيانات الحالية، لذلك لا يستخدم هذا القالب ولا تُنشأ سجلات `INT-*`.

يُحتفظ بالملف فقط كأثر تاريخي يوضح أن المقابلات كانت مخططة سابقًا ثم أوقف تنفيذها. لا يجوز استخدامه لإيهام القارئ بأن مقابلات قد أُجريت.

> **قيد أكاديمي:** هيكل المشروع 1447 يذكر Interviews ضمن Data Gathering Techniques؛ قبول عدم تنفيذها يحتاج تثبيتًا مع المشرف/القسم قبل النسخة النهائية.
